    Why JSON instead of .cgpt?

    The Python edition uses a ZIP + safetensors archive. This static edition has no Python, so it uses a plain JSON weight archive. Both are portable; they are not interchangeable.

    No account, no server

    There is no storage service behind this page. If you clear the browser, the model is gone. Download the archive and keep it wherever you keep important files.
